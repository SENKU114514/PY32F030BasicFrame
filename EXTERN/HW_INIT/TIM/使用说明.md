操作路线：固定准备 → 选择周期中断、PWM 或手动计时 → 检查返回状态。

@ 固定准备
@ 使用周期中断
@ 输出 PWM
@ 手动计时

# 固定准备

在调用文件中引用 `HW_INIT/TIM/TIM_init.h`；初始化放在启动阶段，每个用途一次，开始／停止计时按需调用。

选择定时器 → 使用空闲的 TIM1／TIM3／TIM14／TIM16／TIM17 → 当前框架 TIM1 已用于 MAG 时基，同一定时器不要混用周期中断、PWM 和手动计时。

# 使用周期中断

需要周期任务 → `HW_TIM_COUNT_IT_init()`，传入定时器、方向 `UP`／`DOWN` 和周期毫秒数 → 返回 `HW_TIM_STATUS_OK` 后等待更新中断。

需要处理更新事件 → 在业务文件实现对应的 `TIM1_UpdateCallback()`／`TIM3_UpdateCallback()`／`TIM14_UpdateCallback()`／`TIM16_UpdateCallback()`／`TIM17_UpdateCallback()` → 中断内简短处理并返回。

# 输出 PWM

需要 PWM → `HW_TIM_PWM_init()`，传入定时器、`TIM_PWM_Channel_e` 中匹配的通道引脚、频率 Hz、占空比 0～100 → 返回成功后输出。

选择通道引脚 → 确认与 TIMx 一致、封装实际引出且未被调试或外部晶振占用 → 由接口完成 GPIO 复用配置。

# 手动计时

需要微秒计时 → `HW_TIM_TIME_US_init()` → 成功后用 `HW_TIM_TIME_US_Start()` 开始，用 `HW_TIM_TIME_US_Stop()` 停止并传入结果变量地址。

需要毫秒计时 → `HW_TIM_TIME_MS_init()` → 成功后用 `HW_TIM_TIME_MS_Start()` 开始，用 `HW_TIM_TIME_MS_Stop()` 停止并传入结果变量地址。

选择计时单位 → US 或 MS 接口成组使用，量程均为 0～65535 个对应单位 → 同一定时器接口不可交叉执行，开始和停止可在 GPIO 中断中调用。

需要重新计时 → 再次调用对应 `Start()` → 从零开始；重复 `Stop()` 可读取上次停止结果。

停止返回 → 仅 `HW_TIM_STATUS_OK` 时使用输出值 → `OVERFLOW` 表示超量程，`NOT_STARTED` 表示未开始，错误时输出变量不变。
