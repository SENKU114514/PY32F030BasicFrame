操作路线：固定准备 → 初始化 → 按需写入、读取或先写后读 → 检查结果。

@ 初始化

@ 读取数据

# 固定准备

在调用文件中引用 `HW_INIT/I2C/I2C_init.h`；初始化放在启动阶段，每条总线一次，传输按需调用。

接线时 → 从 `I2C_SCL_Pin_e`、`I2C_SDA_Pin_e` 选择实际引出的引脚，连接外部上拉电阻 → 确认引脚未被其他功能占用。

# 初始化

开始使用 → `HW_I2C_init()`，依次传入 `I2C_BUS1`、SCL、SDA、速度 `100000` 或 `400000` → 返回 `HW_I2C_STATUS_OK` 后通信。

已经初始化 → 相同配置可重复调用，不同配置返回 `HW_I2C_STATUS_ALREADY_INITIALIZED` → 保持原配置使用。

# 写入数据

需要发送 → `HW_I2C_Write()`，传入总线、7 位设备地址、数据地址和非零字节数 → 等待返回。

# 读取数据

需要接收 → `HW_I2C_Read()`，传入总线、7 位设备地址、接收数组和非零字节数 → 成功后使用数组内容。

# 先写后读

需要先指定寄存器再读取 → `HW_I2C_WriteRead()`，传入总线、设备地址、写数组及长度、读数组及长度 → 使用重复起始完成读取。

# 检查结果

填写设备地址 → 直接传入 7 位地址，不左移 → 接收数组容量至少等于请求长度。

执行传输 → 在主循环中调用阻塞轮询接口，不在中断中调用 → 仅返回 `HW_I2C_STATUS_OK` 时按成功处理，其他状态交给业务处理。
