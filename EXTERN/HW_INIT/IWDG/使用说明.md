操作路线：固定准备 → 启动看门狗 → 定期喂狗。

@ 固定准备
@ 启动看门狗
@ 定期喂狗

# 固定准备

在调用文件中引用 `HW_INIT/IWDG/IWDG_init.h`；启动放在系统初始化完成后执行一次，喂狗放在正常业务执行路径中周期执行。

# 启动看门狗

确定复位等待时间 → `HW_IWDG_Init()`，传入 `FeedTime` → 开始定期喂狗。

设置 `FeedTime` → 按 `uint8_t` 范围 0～255 填写重装载值，并非秒数 → 超时时间按 `(FeedTime + 1) × 32 / LSI频率` 秒估算，喂狗周期需留足余量。

# 定期喂狗

确认本轮业务正常运行 → 执行 `FEED_DOG` → 在下次超时前再次执行。

需要长时间阻塞或休眠 → 先确保不会超过看门狗超时 → 本模块没有暂停接口，低功耗模块也不暂停已启动的 IWDG。
