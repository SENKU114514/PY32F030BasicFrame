操作路线：固定准备 → 配置输出或输入 → 按需设置电平、读取电平或处理外部中断。

@ 固定准备
@ 控制输出
@ 读取输入
@ 使用外部中断

# 固定准备

在调用文件中引用 `HW_INIT/GPIO/GPIO_init.h`；初始化放在启动阶段，每个用途配置一次。

选择引脚 → 使用 `GPIO_types.h` 中的 `GPIO_index_e` 名称 → 确认所选封装有该引脚且未被其他功能占用。

# 控制输出

需要输出 → `HW_GPIO_OUT_init()`，传入引脚和 `NO`／`UP`／`DOWN` → 返回 `HW_GPIO_STATUS_OK` 后设置电平。

需要拉低、拉高或翻转 → `HW_GPIO_SET_Pin()`，传入引脚和 `LOW`／`HIGH`／`TOGGLE` → 检查返回状态。

# 读取输入

需要输入 → `HW_GPIO_INPUT_init()`，传入引脚和上下拉 → 返回成功后读取。

需要当前电平 → `HW_GPIO_Get_SingleKey()`，传入引脚和有效的 `uint8_t` 变量地址 → 成功后读取 0／1；该接口不做按键消抖。

# 使用外部中断

需要边沿触发 → `HW_GPIO_INPUT_IT_init()`，传入引脚、上下拉和 `GPIO_IT_RISING`／`GPIO_IT_FALLING`／`GPIO_IT_RISING_FALLING` → 返回成功后等待中断。

选择中断引脚 → 使用当前映射支持的 A／B／F 端口 0～8 号引脚 → 同号引脚只能选一个端口，冲突返回 `HW_GPIO_STATUS_IT_CONFLICT`。

需要响应事件 → 在业务文件实现同名 `HW_GPIO_INPUT_IT_Callback()` → 根据 `GPIO_index` 处理并尽快返回；中断入口已由 `GPIO_init.c` 提供。
