操作路线：固定准备 → 初始化唤醒按键 → 按需进入休眠 → 长按唤醒后继续业务。

@ 固定准备
@ 初始化唤醒按键
@ 处理板级负载
@ 进入休眠
@ 唤醒后继续业务

# 固定准备

在调用文件中引用 `HW_INIT/LOWPOWER/LowPower.h`；初始化放在启动阶段执行一次，休眠入口放在主循环按需调用。

使用 `LowPower_key.h` → 由 `LowPower.c` 内部按 10ms 采样并确认 3 秒长按 → 业务层无需单独调用该文件中的函数。

# 初始化唤醒按键

选择未占用且支持 GPIO 外部中断的按键引脚 → `HW_LowPower_init()`，传入引脚、上下拉和有效电平 `LOW`／`HIGH` → 返回 `HW_LOWPOWER_STATUS_OK` 后允许休眠。

# 处理板级负载

需要关闭板外负载 → 在业务文件实现 `HW_LowPower_PrepareCallback()` → 准备完成返回非零，返回 0 取消本次休眠。

需要恢复负载或撤销准备 → 实现 `HW_LowPower_RestoreCallback()` → 恢复原状态；该回调不可依赖中断或阻塞等待。

# 进入休眠

主循环允许休眠且全局中断开启 → `HW_LowPower_Enter()` → 暂停普通外设并进入 Stop1，长按确认后返回。

外设忙或无法暂停 → 检查 `HW_LOWPOWER_STATUS_PERIPHERAL_BUSY`／`HW_LOWPOWER_STATUS_SUSPEND_FAILED` → 处理后再尝试。

已启动 IWDG → 先规划超时与喂狗策略 → 该接口不暂停 IWDG，不能据此无限期休眠。

# 唤醒后继续业务

进入时按键已按下 → 先松手，再连续按住 3 秒 → 短按会继续休眠。

休眠接口成功返回 → 恢复原有受支持的 4／8／16／24／48MHz 时钟及外设 → 继续业务；MAG tick 不累计休眠时间。

需要屏蔽本次唤醒按键的业务动作 → 等待松手后重置业务按键状态机 → 再恢复普通按键处理。
