操作路线：准备缓存并初始化 → 数据到达时入队 → 业务循环取出 → 处理数据。

@ 初始化
@ 暂存收到的数据
@ 取出数据处理
@ 接入中断或多个任务

# 初始化

数据随时到达、业务需要稍后处理时 → 使用这个字节队列，先放入的数据先取出。

准备一个持续保留的 `Queue` 对象，以及至少 `QUEUE_SIZE` 字节的缓存；当前 `QUEUE_SIZE` 为 64。

启动时调用一次 → `Queue_Init()`，传入队列地址、缓存首地址和 `QUEUE_SIZE`。

当前 `Queue.h` 缺少 `Queue_Init`、`Queue_Push`、`Queue_Pop` 的函数声明，正式跨文件调用前需要先补齐声明。

当前实际容量固定按 `QUEUE_SIZE` 运行，不能只改初始化的 `size` 来调整容量。

# 暂存收到的数据

收到需要暂存的一个字节时 → 调用 `Queue_Push()`，传入队列地址和该字节。

返回 `SERVER_STATUS_OK` → 已入队；返回 `SERVER_STATUS_ABOVE_LIMIT` → 队列已满，该字节没有存入，由业务决定保留重试还是丢弃。

# 取出数据处理

业务循环有机会处理时 → 调用 `Queue_Pop()`，传入队列地址和接收字节的变量地址。

返回 `SERVER_STATUS_OK` → 使用取出的字节；该字节已自动出队，不需要另外删除。

返回 `SERVER_STATUS_NO_DATA` → 队列为空，本轮停止取数，下轮再检查；无需固定毫秒周期。

队列不区分整条指令，取出的字节仍需由业务组包或解析。

# 接入中断或多个任务

同一个队列不要同时入队和出队；若跨中断或任务调用，需在外部保护完整的队列操作。
