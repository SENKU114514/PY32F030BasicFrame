操作路线：启用日志 → 初始化串口 → 需要时打印 → 按需关闭日志。

@ 初始化
@ 打印运行信息
@ 关闭日志

# 初始化

工程宏定义设置 `LOG_ENABLE=1`；当前 Keil 工程已启用。

启动时调用一次 → `Log_init()`，返回 `LOG_OK` 后使用；当前 `app_main_init()` 已有日志初始化调用，不要重复接入。

默认使用 UART2、TX A4、RX A5、波特率 115200；串口工具配置为相同波特率。

需要换串口或引脚 → 修改 `LOG.h` 中的 `UARTx`、`TX_pin`、`RX_pin`；波特率在 `LOG.c` 的 `Uart_Rate`。

使用前确认串口及引脚未被其他功能占用。

# 打印运行信息

业务运行到需要观察的位置 → 使用 `LOG_DEBUG()`，传入格式文本和对应变量。

需要换行 → 在格式文本中加入 `\r\n`；无需固定循环维护。

默认每次最多输出 127 字节，超长内容会截断；在普通业务位置打印，避免占用中断或严格定时流程。

# 关闭日志

将工程宏 `LOG_ENABLE` 设为 0 → 重新编译，`LOG_DEBUG()` 不再输出。

关闭输出不会让单独调用的 `Log_init()` 失效；不需要占用串口时，也不要单独调用它。
