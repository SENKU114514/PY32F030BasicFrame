操作路线：初始化 → 接入下降沿 → 循环取帧 → 读取地址和命令 → 执行业务。

@ 初始化
@ 固定接入接收
@ 取出遥控指令

# 初始化

准备一个持续保留的 `IR_Receive_t` 接收实例，以及一个 `IR_Receive_Frame_t` 输出对象。

开启 GPIO 下降沿中断前 → 调用 `SERVER_IR_Receive_init()`，传入接收实例地址。

# 固定接入接收

自行配置红外输入引脚的下降沿中断，以及连续的 32 位微秒时间戳。

每次下降沿 → 在同一个、不嵌套的中断入口调用 `SERVER_IR_Receive_Edge()`，传入接收实例地址和当前微秒时间戳。

时间戳不能使用毫秒 tick、直接读取的 16 位计数值或单段测量耗时。

# 取出遥控指令

主循环或短周期任务中反复调用 → `SERVER_IR_Receive_Get()`，传入接收实例和输出对象的地址。

返回 `IR_RECEIVE_OK` → 读取输出对象的 `data[0]` 地址、`data[2]` 命令，在这里填写业务动作。

返回 `IR_RECEIVE_EMPTY` → 本轮跳过；其他返回值表示本次数据不可用。

取帧后自动释放缓存，不需要手动清标志；及时取走，一帧未取走时会丢弃新边沿。

当前只支持标准 NEC 正常帧，不输出长按重复帧，也不支持扩展 NEC 地址。
