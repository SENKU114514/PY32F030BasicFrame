操作路线：初始化 → 每 1ms 扫描 → 读取按下／松开状态 → 按需处理双击。

@ 初始化
@ 固定扫描
@ 根据按下或松开执行动作
@ 处理双击

# 初始化

准备一个持续保留、初始清零的 `KEY_FSM_Key_Info_t` 对象，填写 `GPIO_index`。

启动时保持按键松开 → 调用 `SERVER_KEY_FSM_init()`，传入对象地址；返回 `KEY_FSM_OK` 后继续。

初始化会把当前电平作为默认松开电平；引脚采用无内部上下拉输入，硬件需提供稳定的默认电平。

# 固定扫描

每隔 1ms 调用 → `SERVER_KEY_FSM_ALL_STATE()`，传入同一个按键对象地址。

扫描后检查该对象的 `Key_Infomation`，在这里连接业务动作。

# 根据按下或松开执行动作

`Key_Infomation` 为 `KEY_FSM_DOWN` → 已确认按下。

`Key_Infomation` 为 `KEY_FSM_UP` → 当前松开；启动时也会处于此状态。

只想执行一次动作 → 由业务记录上次状态，在进入目标状态时执行；不要每轮重复触发。

消抖状态 `KEY_FSM_DOWN_DELAY`、`KEY_FSM_UP_DELAY` → 等待后续扫描，不作为确认动作。

# 处理双击

`Key_Infomation` 为 `KEY_FSM_DOUBLE` → 在这里处理双击业务。

当前版本双击状态不会自动退出；处理后需清零 `Key_Down_Times`、`Key_Delay_Time`，并把 `Key_Infomation` 恢复为 `KEY_FSM_UP`。

当前没有独立的单击确认事件，也未实现 `KEY_FSM_PUSH_LONG` 长按识别；多按键共用内部计数，不能直接按独立多按键使用。
