# 引用头文件

-> 当前 main.h 已集中包含 SYS、GPIO、TIM、USART、I2C、IWDG、MAG，以及 SERVER 的 JSON、IR、QUEUE、KEY、LOG；业务文件包含 main.h 即可看到这些接口。
-> Keil 和 IAR 已加入这些模块的源文件，沿用 PY32F002Bx5 → PY32F002BPRE 的自动识别；原 F030 分支保留。
-> APP/Input/Output、RTOS 本轮不改；ADC/EXAMPLE 空壳不接入，SPI/DMA、LOWPOWER、002B PWM 继续保持上一轮未启用范围。

# 初始化所需模块

-> SYS/MAG 已沿用当前框架初始化；其他模块由调用者按需要初始化，加入 main.h 不会启动外设。
-> USART 的 002B 分支支持 UART1；TX 为 A3/A6/A7/B4/B6（AF1），RX 为 A2/A4/B5（AF1）或 A7（AF3）。选择实际封装引出的引脚，TX/RX 不能用同一引脚。
-> I2C 的 002B 分支支持 I2C_BUS1；SCL 为 A2/B3，SDA 为 B4/B6，均为 AF6，板上需要外部上拉。
-> 上述映射依据本地 PY32F002B 数据手册表 3-4、3-5；PA2/PB6 是调试相关引脚，不确定接线时不要选择它们。
-> LOG 默认关闭；启用 LOG_ENABLE=1 后先调用 Log_init 并检查结果。002B 默认 UART1、TX_A3、RX_A4、115200；F030 保留原默认配置，UARTx/TX_pin/RX_pin 可通过工程宏覆盖。
-> IWDG 仅在显式调用 HW_IWDG_Init 后启动，启动前先安排喂狗；本次未加入自动启动或喂狗任务。

# 调用模块接口

-> JSON 使用原解析接口；IR 继续由外部提供下降沿和连续 32 位微秒时间戳，MAG 的毫秒 tick 不能直接作为 IR 时间戳。
-> KEY 沿用原状态机，按原约定约每 1ms 调用；本轮补上 GPIO 读取失败返回，未重写按键算法或多按键计时逻辑。
-> QUEUE 保留原实现，调用时提供至少 64 字节缓冲区；当前仍固定按 64 字节使用，传入 size 不改变实际容量。
-> 本轮已验证 002B 编译链接以及 F030 编译；尚未上板验证串口、I2C、按键、看门狗，IAR 仅同步工程配置。
